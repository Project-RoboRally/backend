# backend

## Prerequirements

[Java Zulu-25](https://www.azul.com/downloads/?version=java-25-lts&package=jdk-fx#zulu)

[Gradle 8.13](https://gradle.org/releases/)

## Get started

```bash
run `./gradle clean install` to install all deppendencies
```

## Development


### Run project
To run the project, use the following command

```bash
./gradle run
```

### Run Unit tests
To run unit tests using JUnit 4 run

```bash
./gradle test
```
